

\# Self-Validating AI Agent for Automated Exploratory Data Analysis



\*\*An AI-powered framework for automated data analysis, result validation, and evidence-grounded insights.\*\*



\---



\## 📌 1. Project Overview



This project automates parts of the Exploratory Data Analysis (EDA) workflow using Python, validation mechanisms, and evidence-grounded insight generation.



\## 🎯 2. Project Objectives



\- Automate repetitive EDA tasks.

\- Validate analytical results and generated insights.

\- Support recovery from selected execution errors.

\- Connect findings to supporting evidence.

\- Generate summaries and recommendations.



\## 🚀 3. Key Features



| \*\*Feature\*\* | \*\*Description\*\* |

|---|---|

| \*\*Data Profiling\*\* | Examines dataset structure and data quality. |

| \*\*EDA Planning\*\* | Organizes analytical tasks into a workflow. |

| \*\*Code Execution\*\* | Executes analytical operations. |

| \*\*Result Validation\*\* | Checks analytical outputs. |

| \*\*Self-Correction\*\* | Attempts to recover from supported errors. |

| \*\*Insight Validation\*\* | Evaluates insights against analytical evidence. |

| \*\*Evidence Mapping\*\* | Links findings to supporting results. |

| \*\*Recommendations\*\* | Generates recommendations from findings. |

\## ⚙️ 6. Installation



\*\*Step 1: Clone the repository\*\*



```bash

git clone https://github.com/arkatvijay0/Self\_Validating\_Data\_Agent.git

cd Self\_Validating\_Data\_Agent

```



\*\*Step 2: Activate the environment\*\*



```bash

conda create -n data\_agent python=3.11

conda activate data\_agent

```



\*\*Step 3: Install dependencies\*\*



```bash

python -m pip install -r requirements.txt

```



\## ▶️ 7. Run the Application



```bash

streamlit run app.py

```
